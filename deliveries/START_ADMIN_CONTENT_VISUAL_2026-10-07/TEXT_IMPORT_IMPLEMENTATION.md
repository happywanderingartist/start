# 文字识别实施记录

本批视觉已由用户确认。范围：独立文字识别弹窗、真实本机模型、逐条编辑与高德选择、地点集合/路线草稿批量导入、撤销与验收。正式账号、数据库、公开发布不在本批范围。

## GitHub 核对与方案

使用 Agent Reach 的 GitHub 路由；公开仓库页面与官方 Release API 核对。llama.cpp（ggml-org，MIT，约131k stars，星数不作质量结论）包含 tests、CI、grammar 和 server 示例。2026-10-05 v0.6.0 Release 指向 b11429；已读 server 文档，支持 OpenAI 兼容请求和 JSON schema 约束。官方 Windows CPU x64 包约19.4MB，采用便携方式而非远程安装脚本。可复用优势：本机 CPU 推理与约束输出，无需收费 API；局限：本机须保持运行，小模型可能遗漏地名，结构化输出不证明地理或艺人事实。未运行上游完整测试。

当前模型为官方 Qwen/Qwen2.5-1.5B-Instruct-GGUF 的 Q4_K_M，Apache-2.0，1117320736字节。初测0.5B出现遗漏及人名误判，保留 LOCAL_MODEL_0_5B_CHECK.json 后更换1.5B；未把失败试验宣称为有效识别。当前模型 SHA-256 为 6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e，与官方元数据一致；MODEL_1_5B_MANIFEST.json、运行包 DOWNLOAD_MANIFEST.json 和许可证保留在 local-extractor。官方模型卡提供 llama.cpp 使用方式。无全局安装，无云端模型调用，无账号密钥读取。文字识别本地免费不等于云服务器或高德服务永久免费。

参考： https://github.com/ggml-org/llama.cpp 、 https://github.com/ggml-org/llama.cpp/tree/master/tools/server 、 https://github.com/ggml-org/llama.cpp/releases/tag/b11429 、 https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF 。此前 instructor 结构化校验先例沿用 DESIGN.md 的分析。

## 使用与边界

打开 http://127.0.0.1:4327/#route ，点击“从文字识别”。内容库与地点编辑也有入口；地点场景生成独立草稿，不强迫创建路线。粘贴原文 → 核对名称/城市 → 查询高德候选或地图选择 → 勾选加入 → 本页草稿。需重新启动时，在PowerShell运行本目录 START_TEXT_IMPORT.ps1；已监听的服务保留，不重复启动。脚本未设置自动开机或外网访问。

同名分店/跨城市必须由人选定POI。城市未知留空；已有默认城市只作用户指定兜底。模型输出错误仍可能漏识别，用户可修改/手动补充。当前艺人库是原型内两位艺人的演示列表，之后与真实数据源统一。单批最多30候选，原文最多3500字；过长不静默截断，可分段导入。

所有新地点、导入贡献和路线保存均为当前页面内存，刷新重置；不是数据库持久化或真实平台发布。关闭/取消无批量写入；已编辑/被引用地点不被撤销删除。正式管理身份、审核写库、跨设备共享及上线部署待后续批次。
