# 原型验收标准

## 页面与导航

- [ ] 390×844 视口无横向滚动；
- [ ] 首页、路线详情、路线进行中可相互跳转；
- [ ] 浏览器后退不会导致明显空白或状态丢失；
- [ ] 底部导航不遮挡主按钮和内容。

## 首页

- [ ] 用户进入后能在首屏看到主文案和输入框；
- [ ] 快捷条件可点击并反馈到输入区；
- [ ] 示例需求和推荐卡都能进入同一路线详情；
- [ ] 未实现导航项有清晰反馈。

## 路线详情

- [ ] 展示 5 个有序地点；
- [ ] 每两个地点之间都有距离和时长；
- [ ] 不出现固定“几点到几点”；
- [ ] 地点卡可以展开和折叠；
- [ ] 首屏能感知路线连续性；
- [ ] “开始复刻”是最醒目的主动作。

## 路线进行中

- [ ] 可选择高德或百度；
- [ ] 可记住地图偏好；
- [ ] 模拟导航返回后保留当前站；
- [ ] “我已到达”推进到下一站；
- [ ] 刷新后进度仍在；
- [ ] 完成全部站点后进入完成状态；
- [ ] 重置进度需要二次确认。

## 视觉与可访问性

- [ ] 正文和背景对比度清晰；
- [ ] 主要点击区域不小于约 44×44 像素；
- [ ] 不仅依靠颜色表达完成状态；
- [ ] 动画不影响阅读和操作；
- [ ] 玻璃效果不降低文字清晰度；
- [ ] 页面只有一个主视觉按钮。

## 交付说明

5. 本地启动命令；
6. 下一轮最值得测试的问题。
