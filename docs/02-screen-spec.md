# 三屏页面规格

## 01 首页

### 用户任务

理解产品用途，并进入一条可体验的路线。

### 信息顺序

1. 顶部轻量品牌标识；
2. 主文案；
3. AI 输入框；
4. 快捷条件；
5. 最近/推荐路线卡；
6. 底部导航：首页、社区、行程、我的。

### 交互

- 点击输入框可输入自然语言；
- 点击快捷条件写入输入区；
- 提交示例需求后显示短暂“正在整理星迹”状态，再跳转路线详情；
- 点击推荐路线直接进入详情；
- 社区、行程、我的在本轮显示“后续版本开放”，不实现页面。

### 视觉原则

- 第一屏不堆内容；
- 只有一个高优先级主动作；
- 玻璃效果仅用于主要输入卡和路线卡；
- 不使用大量星星、渐变和装饰图标。

## 02 路线详情

### 用户任务

判断这条路线是否值得复刻，并理解路线如何连接。

### 顶部摘要

- 安溥·南京老城巷陌；
- 南京｜5 个地点｜约 2 小时；
- “原型路线，POI 待核验”轻提示；
- 返回、收藏、分享图标可以有反馈但不需要完整功能。

### 星轨路线

- 纵向排列地点；
- 地点左侧或背景形成连续星轨；
- 两卡之间展示“步行约 X 分钟 · X 米”；
- 卡片折叠时只显示序号、地点名和一句摘要；
- 展开后显示图片占位、明星关联、拍照/菜单/提醒等内容；
- 同一时刻允许多个卡片展开，不强制手风琴。

### 底部操作

- 固定主按钮“开始复刻”；
- 次级操作“调整路线”；
- 调整路线本轮只显示说明弹层，不实现完整编辑器。

## 03 路线进行中

### 用户任务

明确现在要去哪里、怎样导航，以及完成后如何继续下一站。

### 页面结构

- 顶部：路线名称和完成进度；
- 当前站大卡；
- 下一段距离和时长；
- 全路线简化星轨；
- “导航下一站”主按钮；
- “我已到达”次级按钮。

### 地图选择弹层

- 高德地图；
- 百度地图；
- 记住我的选择；
- 取消。

### 模拟导航

选择地图后进入一个清晰标注的“外部地图模拟页/弹层”，显示目的地和“返回路线”。返回后路线进度不变化；点击“我已到达”后才完成站点并进入下一站。

### 完成状态

第五站完成后展示简洁完成反馈；纪念小卡只显示“后续版本生成”，本轮不制作卡片编辑器。
