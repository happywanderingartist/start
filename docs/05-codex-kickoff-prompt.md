# 给 Codex 的启动提示词

请先阅读根目录 `AGENTS.md`、`README.md` 和 `docs` 下全部交接文件，再开始工作。

目标：制作一个移动端优先的可点击网页原型，仅实现“首页—安溥南京路线详情—路线进行中”纵向主链。

技术建议：React、TypeScript、Vite、React Router、原生 CSS 或轻量 Tailwind；使用本地 JSON 和 localStorage，不接后端、真实 AI 或地图 API。

执行要求：

1. 先检查项目目录并输出简短实现计划；
2. 如果目录只有文档，则初始化最小 Vite React TypeScript 项目；
3. 建立可复用的地点卡、星轨连接、底部导航、地图选择弹层和进度组件；
4. 严格使用 `docs/seed/route-anpu-nanjing.json`，不要编造为已核验数据；
5. 实现全部关键交互和 localStorage 状态；
6. 在约 390×844 视口运行并逐项检查验收标准；
7. 修复明显的布局、状态和控制台错误；
8. 最后汇报完成项、差异、已知问题和启动方式。

设计方向：简洁、轻量、圆角、略带玻璃层次；星轨只用于表达路线连接，不堆积抽象宇宙元素。主题色使用低饱和紫蓝或灰紫，确保文本对比度。

禁止事项：

- 不新增聊天、支付、实时位置、完整社区或审核后台；
- 不将模拟导航描述为真实高德/百度接入；
- 不为追求视觉效果牺牲可读性；
- 不在没有说明的情况下改变产品流程。
