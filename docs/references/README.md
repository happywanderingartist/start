# UI参考图说明

此目录用于存放用户之前提供的界面截图。

使用原则：

- 借鉴留白、圆角、透明层次和信息密度；
- 不复制原产品的品牌、图标、排版和完整布局；
- 第一轮只服务首页、路线详情和路线进行中；
- 如果参考图与交互规格冲突，以交互清晰和验收标准为准。

## 已确认的首页视觉基准

- `start-home-light-visual-baseline.png`：`start` 首页浅色「晨雾版」，已由用户确认保留。
- 后续首页设计沿用淡奶油紫背景、深紫立体标题、柔和 3D 星体、浅色磨砂搜索框，以及从左侧边缘探头的小型棉花娃娃。
- 此图是视觉方向基准，不等同于可直接上线的界面资产；实现时应使用真实文字、组件与独立角色素材还原。

## 已确认的 P3 路线详情视觉基准

- `start-p3-route-detail-visual-baseline.png`：`start` P3 路线详情页，已由用户确认。
- 后续功能页沿用奶油白底、黑色粗标题、粉紫黄蓝功能色、扁平时间线、轻边框与黑色主操作按钮。
- 页面信息顺序固定为路线摘要、路线顺序、调整路线与开始复刻；装饰只来自功能节点，不额外加入娃娃、星体或卡通图形。

## 已确认的 P4 路线调整视觉基准

- `start-p4-route-edit-visual-baseline.png`：`start` P4 路线调整页，已由用户确认。
- 页面支持拖动排序、删除地点、查看相邻步行时间、恢复原顺序和保存路线。
- 编辑状态用细紫色描边和占位间隙表达；删除保持次级，黑色“保存路线”是唯一强操作。

## 已确认的 P5 路线进行中视觉基准

- `start-p5-route-in-progress-visual-baseline.png`：`start` P5 路线进行中页，已由用户确认。
- 页面信息顺序固定为当前进度、当前站、导航/到达操作、下一站与全程进度。
- 娃娃仅作为当前站卡片右下角的小型陪伴元素；打卡为可选支线，不阻断继续行程。

## 已确认的 P6 到达地点视觉基准

- `start-p6-arrival-visual-baseline.png`：`start` P6 到达地点页，用户从三种方案中选择第 1 版。
- 页面先确认“第 1 / 5 站已完成”，再展示下一站；黑色“继续下一站”是唯一主操作。
- “拍照打卡”保持次级且可跳过，用户之后仍可补记；娃娃只提供轻量到达反馈。

## 已确认的 P7 拍照打卡视觉基准

- `start-p7-photo-checkin-visual-baseline.png`：`start` P7 拍照打卡页，已由用户确认。
- 使用第 2 版的悬浮动作选择框，其余采用第 3 版构图：九宫格辅助线、小型娃娃拖动与缩放、重置、关闭和跳过入口。
- 底部快门区全透明，取景画面延伸到屏幕底部；相册、快门、切换镜头按钮直接悬浮，提示文字使用白色。
- 拍摄后确认保存，再返回路线；本图仅为视觉参考，角色身份和触控尺寸仍需在实现阶段单独验收。

## 已确认的 P8 行程完成视觉基准

- `start-p8-route-complete-visual-baseline.png`：`start` P8 行程完成页，已由用户确认。
- 主标题为“星迹达成”，下方小字为“A trail of stars, now yours.”；路线名称、完成地点数和日期缩小，作为次级信息。
- 沿途照片采用粉紫、淡黄、浅蓝的折叠风琴卡片布局，展开照片统一尺寸；娃娃位于非照片区域，以举手庆祝动作反馈完成状态。
- 黑色“查看我的足迹”为主操作，“生成纪念卡”保留下方小字入口；延续奶油白底与简洁排版。
- 本图为视觉确认稿，不代表折叠交互、角色动作或字体已经实现。

## 已确认的 P9 我的足迹视觉基准

- `start-p9-my-trails-visual-baseline.png`：用户选择第 3 版，按月份归档路线。
- 每条记录使用统一尺寸的小照片、路线名称、完成日期与地点数；整行可进入路线回忆。
- “我的纪念卡”为次级文字入口，延续奶油白底、淡紫淡黄底色与简洁排版。
- 图中行程与数量是展示用示例，不代表真实用户数据；本图仅确认视觉方向。
