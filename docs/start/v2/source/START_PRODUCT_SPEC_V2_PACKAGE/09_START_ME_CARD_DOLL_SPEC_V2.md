# START — Me, START Card & Doll Spec V2

日期：2026-10-01  
状态：P0 个人身份与陪伴对象规格。

## 1. Me 的角色

Me 回答：
> 我是谁，我喜欢什么，我留下了什么。

第一层组合：
- START Card
- Doll
- START Book

三者不做同尺寸 dashboard tiles。

## 2. 推荐层级

顶部：
**START Card preview**

中部：
**Doll / 当前轻状态**

主内容：
**START Book**

次级：
- Collection
- My Routes
- Settings

## 3. START Card

核心：
- 昵称
- 喜欢的艺人 / 本命
- 兴趣标签

查看他人时增加：
- 共同艺人
- 共同社群
- 共同兴趣
- 共同收藏/经历（满足隐私前提）

## 4. 不做 Match Score

禁止：
- 92% 匹配
- 高契合度排名
- 谁更适合做朋友

START Card 只帮助理解共同点。

## 5. START Book

作为 Me 的核心内容资产，入口应明显，但不做数据统计中心。

## 6. Doll 产品定位

Doll 是：

**追星旅程的陪伴角色 / 数字棉花娃娃**

不是宠物。

## 7. P0 Doll 能力

必须：
- Start Home 轻互动
- Journey 陪伴
- 基础动作
- 基础表情

动作候选：
- idle
- walk
- sit
- look
- happy
- arrival reaction
- completion reaction

## 8. 暂缓

- 完整换装
- 衣柜
- 商店
- 成长值
- 货币
- 每日任务
- 喂养/洗澡/睡觉
- 复杂聊天

## 9. Identity Lock

必须保持：
- 脸型
- 五官比例
- 发型基础识别
- 头身比例
- 材质/风格一致性

姿势、表情、服装、角度不能导致“换脸”。

已有已验收角色资产优先作为 authority。

## 10. Doll 与 Poster

海报可出现 Doll，但不是必须视觉主体。优先级低于：
- 用户照片
- 去过地点
- 偶像元素

## 11. START Card 隐私

用户可控制：
- 是否公开艺人偏好
- 是否公开兴趣标签
- 是否公开共同点推断

默认不暴露敏感个人信息。

## 12. 验收

- Me 第一眼不是功能九宫格
- START Card 不是战绩表
- Doll 不出现宠物养成指标
- 角色资产不漂移
- START Book 仍是主要记忆入口
