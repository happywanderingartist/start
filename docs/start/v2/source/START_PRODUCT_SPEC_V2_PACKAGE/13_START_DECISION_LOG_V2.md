# START — Decision Log V2

日期：2026-10-01

## 已锁定

### 产品定位
- 先是追星产品，再是地图产品。
- 核心：可靠追星地点 + 可复刻路线 + 现场体验 + 记忆沉淀。

### 一级导航
- Start / Community / Me
- 无 Go Tab

### Start
- `Start with [ ... ] ?`
- 少量漂浮推荐气泡
- 推荐依据优先：关注艺人 / 已加入社群 / 相似兴趣用户
- Doll 轻互动，非宠物

### Search
- 多实体：Artist / Route / Place / Event
- 搜城市优先级：Artist → Route → Place → Event
- 搜艺人进入 Artist Hub

### Artist Hub
- 艺人照片
- 有足迹城市
- 推荐路线
- 城市用杂志目录式块

### Route Result
优先：
- 封面
- 与偶像关系
- 城市

### Route Detail
优先级：
1. 和偶像有关
2. 我好想去
3. 怎么走

第一屏：大图 + 标题 + why + story

证据：
- 来源链接
- 来源类型
- 核验状态

CTA：
- 开始路线
- 分享

### Journey
- 进入后：Doll + 下一站 + 进度 + Map
- GPS 附近提醒，用户确认
- 到站重点：偶像故事 + 拍照机位
- 默认按顺序，可跳站
- 用户可自行决定结束

### Completion
- 结束后直接自动海报
- 海报重点：地点 / 用户照片 / 偶像元素
- 海报可自由轻量编辑

### START Book
- 相册 + 日记 + 收藏册
- 视觉像真实册子
- 自动保存完整 Journey 记忆

### UGC Route
- 直接新建路线
- 地点核心：名称 / 为什么相关 / 来源证据
- 自动初筛 + 人工审核
- 证据不足可“未核验”发布

### Community
- 个性化混合推荐，不是 Feed

### Event Hub
- 第一屏先基本信息

### Live Trade
- 有什么 / 想换什么 / 区域 / 识别提示
- P0 不做完整 IM

### Me
- START Card + START Book + Doll
- Card 核心：昵称 / 本命 / 兴趣标签 / 共同点
- 不做 match score

### Doll
- P0：Journey 陪伴 + 简单动作/表情
- 不优先复杂换装
- Identity lock

## 后续仍可细化，但不阻塞架构

- 匿名 Journey 最终何时强制登录
- Poster 分享公开范围
- Community Detail 是否在 P0 有轻帖子能力
- Trade 是否需要“我想换”轻响应
- Event 真实数据来源
- 首批正式艺人/路线内容选择
- 地图供应商最终 AMap vs Tencent
- 国内部署 vendor
