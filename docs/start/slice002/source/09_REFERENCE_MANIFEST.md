# 09 — Reference Manifest

## Priority
### A. Original user reference archive
`references/素材.zip`
Use as broad visual inspiration. Do not copy exact people, brand identities, commercial illustrations, or layouts.

### B. Latest strong-style references
`references/latest_style_refs/`
Use for:
- expressive hand lettering
- irregular stars/starbursts
- collage logic
- doodle overlays
- strong youth/fashion energy
- cutout/silhouette treatment
- controlled accent colors

### C. Two latest archival/editorial references
The final two images in the latest set are especially important for:
- off-white/paper field
- central hierarchy
- peripheral image fragments
- numbered archival objects
- handwritten annotations
- controlled asymmetry
- “personal archive / booklet” feeling

This is useful for Artist Hub, Place Detail, START Book and later Memory, but must be adapted to product hierarchy rather than copied as a poster.

## Reference-use rule
Reference images are not source-of-truth UI.
They define:
- mood
- composition ideas
- expression density
- visual vocabulary

The product hierarchy and interaction rules in this package always win over decorative similarity.
