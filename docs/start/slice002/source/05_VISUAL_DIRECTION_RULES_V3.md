# 05 — Visual Direction Rules V3

## North star
**Apple-like clarity + strong youth editorial character + fandom scrapbook semantics.**

More precisely:
**structural calm + expressive youth editorial layer**

The interface must be:
- clear
- convenient
- low-noise
- premium
- visually distinctive
- young/fashion-forward
- recognizably connected to fandom culture

## User reference material
The supplied reference package and latest image references show recurring qualities:
- expressive hand-drawn lettering
- irregular starbursts / star motifs
- doodles and scribbles
- collage / scrapbook / paper-fragment logic
- strong but selective accent colors
- fashion-editorial composition
- image overlays and cutout logic
- central subject + surrounding archival fragments
- small numbered images / stamps / memorabilia feel
- strong whitespace around expressive elements

The last two recent references are especially useful for:
- centered hierarchy
- quiet off-white/paper field
- small peripheral image fragments
- numbered archival objects
- handwritten side annotations
- controlled asymmetry

Do not reproduce any person, brand, logo, font, commercial illustration, or exact composition from references.

## Visual intensity
Do not make every page equally expressive.

Recommended expressive intensity:
- Start Home: 2/5
- Search Results: 1/5
- Artist Hub: 2–3/5
- Route Detail: 2/5
- Place Detail: 2/5
- Poster / START Book later: 4–5/5

## One expressive gesture per page
- Start: floating collected objects + Doll
- Search: editorial index / directory rhythm
- Artist Hub: city booklet/index
- Route Detail: pilgrimage trace
- Place Detail: small practical memory-card objects

## Typography
Maximum three roles:
1. Display/editorial
2. Clear UI body
3. Accent hand-drawn mark

Handwritten display must never carry long body text or critical operational text.

## Color
Base:
- warm white / soft neutral
- near-black main text
- quiet gray secondary
- subtle borders

Accent:
Use one dominant accent per page/context, not rainbow UI.
Possible direction from references:
- acid yellow
- cobalt blue
- vivid orange
- blush pink
- grass green

Idol/event support colors may be temporary accents, not system foundations.

## Shape semantics
- Bubble = discovery
- Row = navigation/action
- Mini Card = compact practical info
- Trace/Mark = route / active relation
- no decorative card proliferation
- avoid capsule/badge zoo

## Radius
Do not round everything.
- Input: 12–16
- Mini Card: 12–16
- Bubble: freer shape allowed
- Sheet: 20–24 top corners
- Rows: generally no card background
- Image: 0/8/12 depending on treatment

## Decorative fandom translation
Translate fandom culture, do not skin the app with clichés:
- photocards → Mini Info / memory objects
- ticket stubs → Event/Memory metadata
- polaroid → Journey reference/photo treatment
- banners → occasional large editorial short phrase
- support color → temporary accent
- pilgrimage stamp → arrival confirmation
- album/booklet → START Book metaphor
- highlighter → active city/current stop mark
- stickers → Poster/Memory, not every functional page
- route book → Route trace

## Density constraints
Per viewport:
- one primary task
- one primary visual focus
- <=2 major container languages
- usually <=1 strong accent
- <=1 dominant decorative gesture
- core content readable in 1–3 seconds

## External benchmark standard
Use the quality bar associated with strong Awwwards/Webby/FWA/Mobbin examples:
- clear hierarchy
- purposeful whitespace
- visual/function integration
- restrained but memorable motion
- strong composition
- responsive integrity
- distinctive identity without harming task completion

Never mechanically copy an award site or Mobbin screen.
