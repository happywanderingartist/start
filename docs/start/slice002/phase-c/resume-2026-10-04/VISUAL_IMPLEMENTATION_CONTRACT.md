# Phase C visual implementation contract — new baseline

A bounded specification for the same five Discovery pages. This document is not a replacement for approved editable Figma pages.

## Shared typography and colors

Brand title only: the approved START artistic lettering character, not a new generic wordmark. Functional Chinese: PingFang SC with Microsoft YaHei / Noto Sans SC / sans-serif fallback; English system sans and tabular ticket data system mono. Do not redistribute Apple font binaries. Title 28, section18–20, body14–16, caption12 logical px; important information is not handwritten.

The measured WCAG contrast ratios are coffee/oat9.54, coffee/ice8.09, coffee/orange3.15, orange/oat3.03. Small normal text must use coffee on oat or ice; orange is for blocks, accents and sufficiently large bold display, not small body text or sole functional status. Keep focus visible independently of color. These calculations do not certify a complete accessibility audit.

## Five frames and states

Home390: reference-based brand title; editable real search input and clear question; small proportionally rendered approved Doll; four categorized light stacks; shuffle with explicit prototype data boundary; read-only step track; Start/Community/Me. Search remains primary. Category sampling changes visible choices without submitting a fixed route. Do not claim catalog contains a category taxonomy unless backed by the read model.

Search390: query/back at top; Artist → Route → Place → Event quiet editorial sections. Preserve IME, query and return scroll, exact artist as a choice, empty/error/retry. No source, verification, distance, duration or long why in default rows.

Artist390: identity, sticky horizontal city index, city chapters and recommended route links. Index click and scroll share one active city. Optional event remains secondary. No fabricated artist photography.

Route390: artist/city, route title, primary START and secondary SHARE; visible stops; lightweight stop preview SOURCE and PLACE; MAP ↓ shortcut and selected stop indication. Source and verification remain separate. No mandatory giant hero, fabricated navigation or Journey state. START explicitly deferred.

Place390: identity; WHY and prominent address within a normal scroll; secondary photo spot/angle and reference; related route/artist. Unknown address, data or media do not masquerade as verified practical information.

Key states: Home focus/typing; Search loading/empty/error/retry; Artist sticky city; Stop Preview; map active; source/verification/reference unavailable; START deferred. Motion: focus/state changes only, restrained transitions; no automatic Doll runtime, reduced-motion gives immediate equivalent states.

320 protects readable text and 44×44 hit targets; 768 adapts search index, artist city context and route/place practical/narrative splits; 1280 bounded layouts for artist/route/place, not stretched phone UI. Existing A/B layout and interactions remain the structural basis.
