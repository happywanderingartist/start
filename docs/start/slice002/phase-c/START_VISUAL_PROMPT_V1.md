## 完整视觉提示词

为START设计面向追星用户的Mobile Web界面，以390×844作为主视口。保持已经验收的信息架构，视觉目标是清新、轻盈、年轻、有收藏感、有细腻材质。内容可以丰富，但必须用清楚的阅读顺序、颜色分区、前后叠放和字号节奏组织；不能把清新理解成大片空白，也不能把有质感理解成厚重阴影。产品结构沿用Apple-like clarity，表达层采用轻手绘、青春编辑感与私人档案语义。

字体：核心短句可以使用自然、轻盈的手写字形，笔画有温和变化、字距舒展，避免儿童涂鸦感、潦草难辨、粗重黑体和高对比报刊大衬线。Start with不是头条，它与输入内容及问号构成一句等待用户补完的邀请。英文可先以Caveat Regular试排，但不能因字体可用就视为定稿；需与参考对照。中文正文采用清晰、偏轻的常规字体，先以Noto Sans SC Regular试排，字形替换仍可讨论。艺术感来自字形搭配、大小和字重节奏，不能所有文字同大同粗。主邀请句建议26–32px；输入18–20px；推荐标签14–16px；辅助信息12–14px；关键正文/地址16px起。字体角色最多三种，长正文/操作/地址不使用装饰手写。正式页面关键正文维持足够对比度。

搜索入口：用Start with [ … ] ?形成一个连续表达，可自然分行但必须看起来属于一句话。输入区使用细下划线、柔和局部底色或轻薄边界；不能是标题下面放一个笨重的矩形表单，不能是巨大胶囊。问号跟随句子，具有疑问节奏，但不单独做按钮、不夸张放大。输入后，用户输入词成为句子的语义重点。Search始终是首页唯一主要任务；辅助说明更轻，不与入口竞争。不新增不必要的搜索图标、菜单或主按钮。

气泡（最新图二）：仅用于首页三个推荐。形状近圆但无需机械同尺寸；边缘轻薄、局部透光，有很克制的颜色过渡与光感。建议尺寸约88–116px，可依据标签长度调整；位置错落、局部前后关系成立，文字不得被遮挡。不要三个同尺寸大圆排队，也不要满屏气泡。薄边和微弱光感表达空气感，不做厚塑料球、金属球或廉价虹彩。文字是清楚的小标签，不是大标题；透明层后背景变化时仍须可读。建议颜色采用少量低饱和浅蓝、薄荷、杏色或淡黄作语义分区，背景保持安静。气泡是用户明确允许的局部通透方向，不自动扩展为整屏粉紫玻璃或巨幅渐变。

卡与册（最新图三、四）：图三用于单张内容卡的内部组织，照片与文字分区，标题/说明/元信息有层次，照片可有可无，卡片存在轻微背层和自然柔影。图四用于一组档案的组织，照片页和文字页轻微错位叠放，露出不同边缘，有限倾角暗示内部内容，名称和元信息安静置于组下。建议圆角12–20px、相对倾角约2–6度、露边约8–20px，只作试排参数。翻阅/展开后必须清楚可读。不要所有模块都加卡片，不做卡墙；不把同一照片到处重复，不把图片和字装进无法编辑的整屏素材。参考该语言到Artist城市章节/路线缩略对象、Place Reference；Search保留目录，Route保留trace。不提前实现START Book/Memory功能。

材质：底色可从暖白#FAF9F6或柔白#F7F8FA试起；正文近黑，辅助灰。色块服务信息分区，背景不铺彩虹。气泡、照片边缘、纸页和Doll必须共享柔和的光线和克制的阴影尺度，各自保持合理物理语义。阴影是层级提示，不是装饰主体；避免粗糙纸纹、厚重投影、满屏贴纸、随机星芒和既有实物文件夹大插画。少量手绘边注需要有内容用途，不能为风格到处添加。禁止照搬参考摄影、品牌与商业字体艺术。

Doll：使用锁定原始资产，不能AI重绘身份或换姿态。首页先按约36×48px试排，实际可见角色大小需看原素材透明留白，后续可微调。放在推荐外围的合适空隙，不居中、不给大底座、不托住推荐、不挡导航。它是轻微陪伴，不是宠物游戏或页面主人公。不得使用饥饿/喂养/EXP等语义。现阶段只设计低频姿态/动效说明或Figma原型，不实现Doll runtime。

动效：让物件关系产生动作，而不是额外撒动画。气泡低幅度缓慢漂移，聚焦搜索时静止或轻微退让；卡册是页片展开/收拢，被选中对象略前移；Doll仅偶尔回应，避免持续走动。建议状态过渡180–280ms、卡册展开240–360ms、气泡位移2–4px且周期6–10秒作为待验证起始参数；不使用强弹簧、粒子、持续大幅摆动或大型视差。关键信息无需等待动画出现。Reduced Motion时停止漂移，使用立即状态变化，所有动作仍可触达。静态参考不能证明真实动效，Figma实现后需验证。

页面分工：首页是邀请句+三个通透推荐气泡+外围小Doll；Search是轻盈的编辑目录，不添加长why/核验/距离时长；Artist是城市索引与章节、受控档案碎片；Route是身份/START/Stops/Map的清楚路径，START高于SHARE、MAP为快捷动作，不能加巨大Hero；Place是WHY、可直接找到的地址及实用信息、档案参考。主导航只有Start/Community/Me，不新增Go。本次只改用户指定的区域；不做API集成、Journey、Event Hub、merge/deploy。

## 逐条协作修改约定

用户给出具体指令后，先读取相关Figma节点和最新画面，再改指定文字/位置/尺寸/组件；保留用户手动改动，不整页重生成。完成后给修改后截图、简短差异与节点链接。必要歧义只问影响结果的一项。不会自动实时监听用户每次编辑；每次指令触发读取和修改。用户未定稿的字体、色值、标志或尺寸明确标记为探索。

START标志独立设计，当前字标仅placeholder，不将现有字体直接称为原创logo。优先探索轻手绘字标的字母关系与识别度，独立小尺寸符号后续讨论；不得用Doll头像替代品牌，也不能未经讨论就把问号、星芒、箭头指定为最终标志。
