## Detailed design prompt

Create a compact START letter-object logo, approximately 60 by 54 px in the 390 px home frame. Arrange all five recognizable letters as one compact, asymmetrical mark, using rounded irregular silhouettes, alternating letter scale, slight rotation, tightly balanced negative space and a single small star. Blue ink is the dominant color. No enclosing app-icon tile is required for this header draft. Do not present plain text as a completed custom brand mark.

Create Start with as an inviting, playful piece of lettering above the existing editable question. Use modest rounded letterforms with restrained imperfect rhythm; alternate baseline by about 1–3 px and rotate individual letters by about 2–4 degrees. Keep the whole phrase near 200 px wide and 45 px high. Use a fine dark outline, predominantly sky-blue fill and only two small mint/peach accents, with at most two tiny irregular stars. Keep the phrase readable at normal 390 px scale. The existing [ artist / city / place ] ? remains the clear actionable search entry. Do not turn the phrase into a giant headline, poster, sticker strip, all-caps slab or children's pet-game interface.

Body and input text remain quiet and readable. Decorative fonts apply only to the mark and short invitation. Keep bubbles, the tiny locked Doll and the accepted page structure intact. This task creates static lettering, not new motion or a new home IA. Native editable Figma text and shape layers, component sources and instances are required; do not paste a generated full-page image.

## Github reference before edit

Read google/fonts/apache/chewy/METADATA.pb, LICENSE.txt and DESCRIPTION.en_us.html, and the googlefonts/pangolin repository structure and license summary. Chewy provides a distributed, reusable display font with rounded irregular glyphs; limitation: Latin-only and not a bespoke START logo. Its verified metadata declares Apache 2.0, not OFL; preserve notices if distributing font files later. No font files are vendored now. Pangolin offers a hand-written rhythm and OFL 1.1, but its upstream repository is archived and it is not evidence of an actively maintained UI framework. Actual Figma font availability was checked before edits: Chewy Regular, Pangolin Regular and several Fredoka styles are available. This draft uses Chewy as an editable construction base with original arrangement; no reference artwork or source code is copied.

Sources: https://github.com/google/fonts/tree/main/apache/chewy ; https://github.com/googlefonts/pangolin . Font evidence is saved under evidence/slice002-phase-c/chewy-*.txt.
