# 已批准票根原型交付

用户在 2026-10-05 明确「审核通过」。本批接入纪念票根与编辑布局：原 Logo、挂孔/挂绳、分段信息栏、大幅照片或图形封面、摘要格、装饰条码和齿边。到访地点单独列出，避免压缩主视觉；长标题和注记延长票面，保留全部文字。版式切换不删除照片，替换照片自动选照片封面。编辑返回保留草稿；明确取消丢弃草稿，恢复票根位置与操作焦点。票根 URL 固定带记录 ID，解决返回后刷新找不到记录的问题。
