# START 首页效果：详细设计提示词

版本日期：2026-10-03。用途：交给设计师、视觉探索工具或 Figma 制作人员的首页设计说明。本文整理用户已表达的偏好，不把旧 Figma 草稿、生成图片或建议参数当成用户已验收的设计。参考图编号采用本包统一 REF_01–REF_28，不沿用各轮重复出现的“图一／图二”。

## 1. 核心概念与设计判断

START 像一本年轻人的旅行杂志：打开首页，就像翻开一本能带你穿梭到不同城市、艺人足迹与地点的刊物。结构安静、清晰、容易使用；表达年轻、生动、艺术、有追星文化和私人旅行档案的感觉。用排版、轻薄纸页、少量照片、手写边注与颜色分块建立质感。图片与文字可以丰富，但必须有明确的视觉主次与留白，不能靠把所有元素缩小、加卡片或堆装饰来容纳内容。

视觉北极星：Apple-like clarity + strong youth editorial + fandom scrapbook。这里的童趣指手绘字的节奏、自然的不完美、颜色的活力与轻微的动作，不是儿童宠物游戏的粗大按钮、夸张玩偶或热闹贴纸墙。杂志感指编排与阅读节奏，不是巨大黑色报纸头条，也不是厚重仿真的摄影道具。

用户已明确：首页有摊开的书的感觉；Start with 更有设计感、童趣、颜色更丰富，并比旧小字样放大；START 要成为有辨识度的标志；一般中英文信息参考 REF_21 的绿色文字气质；非重要文字可参考 REF_20 的手写气质；气泡参考 REF_10；卡册参考 REF_11–12；票根参考 REF_28。用户没有验收任何现有 Logo 形状、具体字体、色值、书脊造型或动效参数。

## 2. 首页信息层级与布局

第一主要视口是 390×844 Mobile Web。保持已有首页任务：输入艺人、城市或地点，发现已有内容。视觉层级为：搜索提问与输入 → 少量推荐气泡 → 小型陪伴 Doll 与边注。主导航只有 Start / Community / Me，不加 Go，不加信息流、Event Hub、完整卡册或新的功能入口。

页首放紧凑的 START 品牌标志，旁边可有很轻的页码、期刊式索引或一句手写边注。不要把大 Logo 和大标题同时塞入首页，不加一整排导航、徽章或解释。搜索区处于页面上部到中部最容易看到的位置；周围留出完整的呼吸区，不用多层框包住标题、输入和提示。

`Start with [ ... ] ?` 是完整的一句邀请与提问。可以在视觉上分为上面的艺术字 Start with 和下面的输入，但两部分要有清楚的关系。问号有轻微的活泼感而且看得见，不能成为巨大装饰；用户反馈曾要求弱化问号与其他元素对搜索的竞争，所以疑问感优先由句子关系、输入留白和字形节奏建立。不要擅自改成聊天机器人问题、AI 对话框或新增问答功能。

输入示例采用“艺人 / 城市 / 地点”，明确这是可输入的搜索入口。框形可以是轻薄、不完全机械的轮廓，也可以是简洁的页内输入线；这是待比较的设计方案。不要像巨大聊天胶囊、厚黑按钮或多层嵌套面板。搜索文字、光标、焦点与提交方式在实际原型中应清楚；静态概念图不能证明输入交互已实现。

推荐区只保留少量气泡，试排可用“苏打绿”“台北”“从一家书店开始”。它们是推荐表达，不是假装真实个性化算法已工作。下半部用摊开纸页承接气泡，让页面像可继续翻阅的旅行杂志；不要在下方新增一个路线路线卡墙。底部三项导航轻而清楚，文字与可点击区域不能被书页、照片或装饰盖住。

## 3. START 标志

参考 REF_13–15：字母可以紧凑组合、略有高低与粗细变化，构成一个有辨识度的整体轮廓。要能成为首页小标志，并为后续小尺寸图标建立可能性。五个字母或具有识别力的原创缩略形应自然连贯，不能只是普通字体打出 START 后称为定稿商标。

旧稿把 ST 与 ART 生硬分成两行，用户认为形状奇怪；不要把这个拼法作为既定方向继续扩展。也不要因为方便就替换为泛用星星、地图定位针或出发箭头。优先探索连贯字母、紧凑负形与一个小型手绘特征的关系；小星芒是可选特征，不是必需品。

标志主版本先能在单色下识别，颜色版本再与首页统一。实际商标字形、字母大小写、是否有独立符号、应用图标版都尚未定稿。参考图只提供结构与节奏，不能复制参考的具体字体艺术、品牌组合或完整构图；本阶段不声称商标注册或权利检索已完成。

## 4. Start with 的艺术字

主要参考 REF_16–18。字母圆润、有手绘感，可以轻微高低变化、倾斜、大小差异，但整体读起来仍然是一句连贯邀请。不要沿着一条死板基线排列所有字，也不要将每个字旋转到破坏阅读。使用较细的深色轮廓，局部颜色可像蜡笔或 marker 的轻填涂，有少量留白与不完全均匀的质地。

标题颜色比旧版更丰富：天空蓝、柔粉、暖黄、浅绿可以在字母间交替，色彩搭配必须有重复关系，不是每个字临时选一个新颜色。参考 REF_16 的轮廓与轻填涂，REF_17 的色块与字母节奏，REF_18 的清楚轮廓与颜色活力；不要复制这些作品的原字形。可用极少量星芒或短笔划帮助表达邀请感，不围一圈贴纸。

比旧的约 31px 基础字形放大，但不能变成报纸头条。可先按 390px 画面上 38–44px 的等效字形、整体约 210–260px 宽试排，再以画面判断；这是建议范围，不是验收过的 Design Token。用户偏好轻盈，童趣与字形饱满并不意味着用极厚黑色字体。REF_19 的黑色大字只可辅助研究字母轮廓，不适合作为首页的视觉重量。

Start with 可以作为独立原创字形资产，但真实输入、辅助说明、导航必须仍是可编辑文字。正式 Figma 中字样要保留字母／矢量层和可复用组件，不能用整张生成图片充当产品 UI。

## 5. 字体系统：统一气质、不同职责

一般中英文信息参考 REF_21 的绿色文字：自然手作的笔触、略带不规则但稳定的轮廓、舒适的字符间距，中文与英文看起来属于同一个系统。不要误读成“所有正文都放大、加粗、变绿”。关键内容如输入、结果名称、地点地址、来源、状态和按钮文字，应能快速辨认，不用低对比细线花体或随意旋转。

非重要信息参考 REF_20：纤细、带手写节奏的中文，少量 marker 划线或强调。适合一两句边注、页码、章节旁注与情绪性小字，不适合大段正文、地址、所有导航或每个气泡标签。手写字是辅助语气，不能抢主标题，也不能靠堆叠异体字体制造艺术感。

艺术标题／一般信息／边注三个角色共享同一套色彩、间距与页内关系。实际字体选择需要试排中英文混排、简体字覆盖、字号和字重；不能声称已识别参考作品的原字体。当前可研究的近似字体包括 LXGW Marker Gothic、霞鹜文楷、Patrick Hand；它们只是候选，现有 Figma 字体设置并非用户已确认的正式 Typography。

建议试排尺度：主要输入约 17–19px，一般标签约 15–17px，辅助说明与边注约 12–14px；中文边注不因“非重要”而小到无法阅读。艺术字最多占一类高表达角色，不让所有页都使用同等强度的手绘标题。

## 6. 颜色、材质与光感

大面积基底接近干净的奶油纸白，可有很淡的纸张质感，但不能整屏黄旧、污渍、颗粒或褪色。主要文字用稳定的深绿或深色墨；彩色块负责分组和节奏，文字不能被反光、透明材质或花纹盖住。

建议起始色盘：纸白 #F6F5EC、深绿墨 #294F47、天空蓝 #8CCEE4、柔粉 #EAA4CA、暖黄 #F2D66D、浅绿 #A6D2AE。这是当前试排建议，不是用户锁定色值。标题、气泡、页边、票根尽量重复这组颜色，避免每个对象使用不同饱和度、阴影和材质。

允许少量透明感与局部柔和光泽来吸收 REF_10 的气泡气质，但不要照搬整屏模糊背景、强玻璃反光或粉紫渐变。纸页和气泡可以有不同质感，却要共享温柔光线、轻薄边缘和克制阴影，不像两个素材库拼接。

## 7. 摊开的杂志与照片

参考 REF_22、REF_26 的“打开一本书”关系，理解两页、书脊、薄纸边和阅读空间，不能复制原人物、原插画或书本造型。首页的书应首先是排版隐喻：两页或页片形成可阅读区域，浅浅的中缝、少量页边就足以表达翻开感。

如果采用具体书形，也必须轻薄，不成为厚重摄影道具。不要夸张透视、厚书堆、很深的书脊或浓重阴影；折痕不能压住搜索和标签。最近生成的概念图只是试验，并未被用户验收；其中写实书本与照片占比偏大的问题属于待复核项，不能反推为必须照做。

照片是清新的城市、街景、书店、旅途片段或与实际内容有关的真实视觉。允许小照片露边、短标题、章节编号和少量手写边注，但不要用没有证据的艺人照片或虚构偶像足迹作正式内容。概念探索里的图片要被理解为氛围样张，不能冒充真实路线或已核验地点。

不要求首页必须有三张照片，也不要求把每个气泡都配一张图。页面内容丰富感由照片与文字的比例、受控叠放、颜色区域和节奏共同建立，不能变成满屏拼贴。

## 8. 气泡与 Doll

气泡核心参考 REF_10：轻盈、不同大小、少量透明层次、自然分布与前后关系。避免机械等距列队、很厚圆边、强发光或按钮式阴影。中心标题清楚，气泡之间和输入之间有完整间距，不压字、不盖主操作。保留少量推荐，不做无限气泡海或全屏推荐算法演示。

Doll 是追星陪伴载体，处在边缘、小比例、低频互动的位置；不占据中央、主标题旁边的大面积，不像突兀放入页面的巨大立牌。它要有自然轻微的姿态或回应，不静止成僵硬大头像，也不持续跳舞抢视线。素材使用已锁定的角色资产，不允许随意生成替代娃娃、换脸、改身份或加入宠物养成内容。

390px 试排可先以可见角色约 24–40px 高来研究比例；带透明边的文件外框可能更大，不能只看图片框尺寸判断娃娃大小。这是探索建议，需要与用户一起看真实画面。气泡与 Doll 的材质、描边、光感和动作要统一，不做写实照片＋塑料 3D 娃娃＋强弹簧气泡的拼接。

## 9. 后续卡片、卡册与票根的统一语言

参考 REF_11 的图文分区和轻微归档层边，REF_12 的一组照片／文字页片露边叠放。同一主题像一个小章节、一册旅行片段，标题与元信息安静地落在正确位置，而不是每个模块都套同样的圆角背景。REF_06–07 可辅助研究叠放的深度与露边，但不要把首页改成卡片墙。

杂志卡片可使用封面图、目录行、章节编号、窄色块、正文与小图之间的差异；不同信息密度对应不同编排。不把 Search 做成小红书信息流，不把 Place 做成交易商品，不新增真正 START Book／Memory 功能。

票根参考 REF_28：轻薄纸、合理缺口、虚线分隔、整齐的元信息、一个视觉重点。用它学习信息编排与物件感，而非复制 Figma 品牌、票号、条码或商业图形。当前可以做旁边的版式样张，不把票券作为首页的新产品入口，也不制造真实活动凭证。

## 10. 动效意图：设计说明，尚未实现

动作像翻阅、整理、轻轻浮动，与旅行杂志语言一致。气泡可以缓慢小幅漂移或轻微错层，在搜索 focus／typing 时减弱或暂停；输入动作最清楚，其余内容退让。Doll 偶尔点头、侧身或做一次微回应，不跟着每次输入反复跳跃。卡册可以轻展开页片与收拢，不能剧烈翻飞或把文字遮住。

建议先探索：气泡位移 2–5px、一个周期约 5–8秒，常规界面过渡约 180–300ms；无强弹簧、无限粒子、抖动字或持续旋转。这些是建议值，不是已验证动效。尊重 reduced motion；降低动效时依然能理解焦点与层级。需要实际原型和设备检查，不能从静态参考图声称动效完成。

## 11. 响应式与状态

390×844 主画面先建立；320px 必须保持搜索可读、气泡不互相挤压、Doll 不盖字。768px 不能只是放大手机：可以让纸页／章节形成更自然的横向编辑关系，搜索仍是中心任务，导航保持现有产品结构。1280px 用刊物的留白、分栏和阅读宽度建立桌面表达，不无限拉长输入与标题。所有响应式方案属于后续正式设计验证，不在本提示词中声称已经实现。

Home 默认／focus／typing 保持同一视觉语言。输入聚焦时背景对象退让，输入值依然是正常可编辑文本；loading／empty／error 在搜索结果流程中清楚呈现，不因为艺术风格隐藏状态或错误重试。首页概念图不需要一次铺满所有状态，也不能仅靠截图证明交互验收。

## 12. 一键使用的主提示词

为 START 设计一张 390×844 比例的 Mobile Web 首页视觉概念。它是一款中国大陆优先的追星旅行发现产品，首页像摊开一本能带人穿梭艺人足迹、城市与地点的年轻旅行杂志。保持 Apple-like clarity + youthful editorial + restrained fandom scrapbook：布局清楚、气质清新、轻薄有质感，丰富但不杂乱。请按本包 REF_13–15 研究原创紧凑 START 标志，避免 ST/ART 生硬拆行；按 REF_16–18 为 Start with 创作彩色手绘字，采用圆润自然的轮廓、细深色描边、蓝粉黄绿的协调填色、少量高低变化与轻微倾角，比旧小字放大但不要成为巨大报纸头条。它与下方 [ 艺人 / 城市 / 地点 ] ? 组成完整提问；真实搜索输入是页面唯一主焦点，清楚可读，不做 AI 聊天框。一般中英文信息参考 REF_21 的自然 marker 手作字感，重要信息清晰；非重要边注参考 REF_20 的纤细手写与少量荧光笔划线。大面积奶油纸白、深绿墨，协调天空蓝、柔粉、暖黄、浅绿；参考 REF_10 的少量轻盈气泡，不同大小、受控不对称、弱透明光感，内容示例为苏打绿、台北、从一家书店开始。下半部以轻薄摊开纸页、浅书脊和少量页码承接内容，参考 REF_22 的打开书关系但不要复制原插画。小照片或旅行片段按阅读需要露边，避免厚重写实书本、过量照片、满屏拼贴。Doll 若有已提供的锁定素材，只以边缘小比例自然陪伴出现；没有素材时保留位置或省略，不生成替代角色。最多两三处细小星芒／笔划，不围住主标题。底部只有 Start / Community / Me。卡册参考 REF_11–12 的页片组合，票根参考 REF_28 的轻纸、缺口、虚线与信息对齐，但不新增首页功能。整屏字体、材质、光感、配色和动作必须属于同一本旅行杂志。输出为视觉探索时明确这是概念，不冒充真实数据或正式可编辑 UI；制作正式 Figma 时使用原生可编辑文字、矢量、组件与响应式布局。

## 13. 负面提示词

不要：高德／百度地图换皮，小红书／微博信息流，闲鱼交易市场，儿童宠物 App，巨大僵硬娃娃，饥饿喂养洗澡 EXP，粉紫玻璃拟态，整屏模糊渐变，giant gradient，强玻璃反光，厚重黑色报纸头条，机械字母排列，ST/ART 生硬拆行，满屏彩虹正文，花体地址与按钮，卡片墙，重复圆角卡片堆叠，满屏胶囊 badge，满屏贴纸，过度拼贴，厚书堆与深书脊，深阴影，炫技翻页，强弹簧，粒子，持续角色表演，额外 Go Tab，虚构个性化算法，任意搜索跳固定南京路线，未核验偶像照片／足迹，假票号／条码，复制商业人物、品牌、字体艺术或完整构图。

## 14. 检查方法与阶段边界

先用一张首页看整体，不批量生成五页。正常尺度第一眼应看到邀请与搜索，其次才注意到推荐、边注和 Doll；输入、导航、标签不被书脊或素材盖住；一般信息读起来像同一字体系统；纸页、泡泡、照片与角色像来自同一套设计；色彩丰富但有稳定重复；照片／边注丰富而不会成卡墙。

正式 UI 的 source of truth 是 Figma。Canva 只用于样板、草图、海报与拼贴；图像生成只提供讨论概念与允许的独立素材。当前 Canva 生成失败、Figma MCP 曾遇额度限制、V3 截图未完成核对，均不是设计验收通过。本文与打包不修改源码、API、schema、现有工作区，也不进入 Journey／Memory／UGC／Community 运行功能、merge 或 deploy。
