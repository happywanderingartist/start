# 登录入口 V1 · 待视觉确认

采用 Interaction Design、Apple Design、Hallmark 的任务内轻量面板：匿名浏览照常，用户首次选择跨设备保存资料/纪念卡时才出现。手机底部单面板、平板中心单面板；不把两张手机稿并排缩进手机，不新增全屏欢迎页。沿用原Logo、奶油底、咖啡文字和冰蓝主按钮；不新增头像插画、营销口号或绿黄大块背景。

视觉文件独立放在 Me 交付的 prototype/login-review/，没有接入页面路由、没有认证逻辑、按钮禁用、没有邮件请求。index.html为邮箱输入稿，waiting.html为查收稿，显式注明未发送。背景复用已确认Me，面板内容可编辑；不是整页图片热区。

结构：原Logo/关闭 → 保存目的 → 邮箱 → 单一发送动作 → 无密码说明 → 暂时不登录。查收状态保留更换邮箱与重发；真实实现必须由成功响应进入查收，失败留在输入状态。发送中防重复，失败保留输入，重发遵循服务端限流，关闭回到原任务并恢复焦点，不丢编辑内容。实际显示的邮箱来自成功请求，不固定使用示例身份。

GitHub先行参考：[shadcn/ui composition](https://github.com/shadcn-ui/ui/blob/main/skills/shadcn/rules/composition.md)。优势是明确对话框标题、描述与移动面板分工；[issue212](https://github.com/shadcn-ui/ui/issues/212) 的局限是iOS键盘可能遮住底部面板，不能仅按桌面截图验收。实现时检验键盘/动态视口、关闭回焦、Escape、焦点陷阱、屏幕阅读器标题、reduced-motion和真实硬件。本批不安装组件库。

待确认此批视觉后实现。真实服务未配置，邮件登录仅为符合交接架构的候选流程；服务选型、邮箱送达、回调白名单与隐私/条款文案须在配置时完成，不能将此稿视为已提供账号服务。
