# START · reference decision record

目标：把用户已确认的年轻旅行杂志风格转为 Phase C 五页设计的共同约束。面向中国大陆 Mobile Web；不重做已验收信息架构。

| 依据 | 置信度 | 保留 | 改变 | 不复制 |
|---|---|---|---|---|
| HOME_SOFT_ORANGE.png，本轮已实际查看 | observed；颜色数值来自已有规范 | 燕麦/咖啡/冰蓝/柔橘、搜索主焦点、轻层叠和小娃娃 | 落地时修正小字对比、字体回退和状态 | 不将图中生成的娃娃直接认定为已批准母版资产 |
| 用户手绘标题与字体参考 | provided，来自本对话图片 | 字母轻微错位、手绘线条、问句亲切感 | 改为 START 自有字形与中英文功能字体角色 | 原艺术字、商标和完整构图 |
| 用户气泡参考 | provided，来自本对话图片 | 轻盈色块与内容聚组 | 减少数量与运动，服从搜索 | 玻璃渐变背景与原新闻产品 |
| 用户卡册/旅行杂志参考 | provided，来自本对话图片 | 纸片层叠、图文节奏、章节索引 | 将记忆卡册语言适配 Discovery 内容层级 | 原照片、密集卡墙和后续 Book 功能 |
| REF_28 票根 | provided，既有计划锁定 | 信息栏、虚线、缺口和图形区关系 | 将来适配 START Memory | 商业品牌、条码功能和原票券内容 |
| Phase B baseline 与 V2 | provided；本轮 Git 状态读取 | 五页结构、四实体及证据入口 | 仅视觉与交互表现 | 不套开源 App 页面或重写业务 |

最终方向：用旅行杂志的章节与目录组织信息，用手绘和纸片表达年轻追星文化；关键操作与地址保持清晰，装饰保持次要。各页共享 token，而不是共享同一种卡片堆叠。

风险：截图不能证明字体名称、真实动效、透明角色资产或可编辑 Figma。2026-10-04 Figma MCP 曾触发额度限制，本轮没有重新检查是否解除；Open Design 不作为绕过该限制的手段。页面尺寸与动效数值属于推断实施起点，需要原型验收。自检不是独立审查。

质量门槛：四个剩余页面各有一张 390 参考；五页的主要动作与重要信息可快速辨认；地址、来源、输入与返回不被纸片遮挡；320 无溢出，768 具有真正响应式重排；字体许可与娃娃 provenance 登记；正式 Figma 可编辑、截图与 prototype 一致；两轮独立 audit 和修复回归记录齐备后再交用户验收。

本记录采用 Open Design 的 reference-design-contract 完整技能；design-md/design-review 目录内仅为上游指针的 catalogue stub 未作为完整工具安装。本文与 DESIGN.md、implementation-handoff.md 已按该技能 P0 checklist 自查，未执行页面实现。
