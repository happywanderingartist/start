# START 产品架构 · 2026-10-06

首页、社区、我的为三个一级入口。Apple Music 的标题层级、内容分组、底部导航与详情返回作为界面底座；旅行杂志的照片、纸色与组合色卡作为内容表达。原 Logo、锁定角色和已确认首页保留。最近用户决定优先于早期探索稿。

| 一级入口 | 主要模块 | 二级页面与归属 |
| --- | --- | --- |
| 首页 Start | 搜索、城市选择、紧凑滚动推荐、分类地点列表、动态娃娃 | 地点、路线、演出、帖子详情；列表按餐厅、咖啡、娱乐、景点、书店筛选。推荐不替代列表。 |

## 两条核心流程

用户贡献地点是缺失模块，现增加独立设计批次：社区城市地点列表 → 上传地点 → 地图选点 → 资料与提交预览 → 我的地点。地图提供新增入口，地点详情提供补充/纠错，Me 管理自己的草稿和投稿；审核公开后才进入城市列表、地图与首页推荐。具体设计与未实现边界见 [PLACE_UPLOAD_SPEC.md](PLACE_UPLOAD_SPEC.md)。本批尚待视觉确认。

发现地点或路线 → 查看详情 → 开始行程 → 到达打卡 → 完成行程 → 编辑纪念票根 → 收入 START Book。社区则是发现社群 → 加入/关注 → 查打卡点、活动与物料集市；加入状态须在返回、刷新与重启后保留。当前演示使用同源会话存储，跨端及重启持久化需要账号服务。

首次进入时选择男娃或女娃，一个账号只持有一个角色，日常页面不提供双角色切换。当前首次选择页只是视觉预览，账号角色绑定尚未实现。装扮页保留换装与换表情，配饰暂缓。首页显示当前演示角色的独立原始图，保持比例；轻微位移与摇摆表达陪伴，可暂停，输入聚焦、后台与 reduced-motion 时停止。首页尚未同步所选服装，也未制作骨骼动作或眨眼序列。

## 角色素材与状态

男娃原始 R02 参考图有五套：舞台/活动风、休闲日常、学院风、居家慵懒、牛仔日常。之前只接入原始图且校验限制换装，属于接入遗漏。本次审阅稿开放五套原始参考局部预览；它们含原稿纸底，尚不等同于五套透明正式素材。女娃已有原始图及四套独立候选图。两角色都有四种表情预览；现有整图切换模型不能将所有表情与服装自由叠加，换表情会恢复原始穿搭，须在素材分层后完善。

账号保存角色 ID；装扮保存 outfit ID、expression ID 和版本；素材目录记录所属角色、来源、尺寸、透明度、身份核验与可发布状态。配饰历史字段暂保留兼容，但无可操作入口。不得以裁剪参考图冒充已完成透明素材，也不得重新生成未经确认的角色身份。

## 推进顺序与验收

先确认本批布局、首页角色比例与动态、男娃五套参考预览；随后整理男娃正式透明素材并检查身份与边缘，再完成账号与唯一角色绑定、装扮持久化、高德定位及真实地点查询，最后接入行程与 Book、社群与集市云端数据。每批仍执行结构 → 视觉稿 → 用户确认 → 实现 → 验证，不将未确认页面合并主原型。

本审阅稿与现有主原型分开保存；设计完成、代码完成、测试通过、已配置、真机可用、用户验收分别记录。六种宽度、返回/状态恢复、键盘与 reduced-motion 检查不能代替真实登录、定位或云端验收。

## 2026-10-07 最新澄清：艺人城市地点集合为主体

搜索艺人 → 选择城市 → 分类打卡地点列表/地图是主流程，不要求站点组成路线，也不要求加入社群才能浏览。城市内容默认“打卡地点”，另有独立“路线”入口；没有路线时地点照常可见。美食可细分餐厅、小吃、甜品等，咖啡、景点、娱乐、书店等可筛选。具体字段映射与本批视觉仍待确认；不删除已有分类数据。

上传地点与上传路线独立：经审核的单个地点/艺人同款贡献可直接进入艺人城市集合；集合由公共地点及艺人关联查询生成，无需另外建路线。路线复用placeId，有独立routeId和有序站点，不因主题艺人自动确认所有地点为艺人到访。单点打卡沿用自由打卡，不要求GPS证据或完成路线。新设计优先艺人页、切城、分类地点列表/地图，再做路线编排；结构依据见 deliveries/START_ROUTE_INTAKE_2026-10-07/ARTIST_CITY_DISCOVERY.md 。本轮只更新文档，未修改原型或数据库。

## 2026-10-07 最新确认：唯一艺人社群与物料自主状态

一个艺人只对应一个社群。城市为社群内内容筛选，不另建城市社群或同艺人主题社群。保留用户申请、平台审批：只能创建尚无社群的艺人社群；已有社群直接加入/关注。最终公开社群须按artistId唯一，申请与审批时处理重复及并发；不擅自删除既有演示数据或迁移真实社群。

物料状态由发布者自行选择。平台不干涉是否交换完成，不追踪或认证完成，不设置双方完成确认，不因接受申请自动视为完成。演出改期、取消或换场馆不向物料发布者发送关联提醒，不自动改变物料状态或集合安排。公共演出仍维护最新资料，演出场馆地址与发布者填写的交换集合点分开。已有申请/接受及自愿交换联系方式规则保持；普通交换申请通知不属于被取消的演出变更提醒。具体状态选项尚待视觉稿确定，不将发布者自行标记称作平台认证。
