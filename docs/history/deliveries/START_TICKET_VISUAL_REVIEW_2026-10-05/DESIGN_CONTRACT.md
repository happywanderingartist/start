# 票根第一版视觉审阅合约

状态：待用户确认。只制作静态、可编辑视觉稿，不连接现有原型，不写保存/收录业务或新的 Memory 状态。所有页面中的按钮是待实现的视觉位置。

结构先使用 Interaction Design 定“查看今天的纪念记录”为主要目的：票根是主体，编辑和收录位于券外，不在海报里堆按钮。Apple Design 负责清晰系统层级、返回、上下文操作；Hallmark 负责结构差异和克制，票根为纵向券、编辑页为预览加分组设置，而非同一套卡墙。现有整体设计已明确，Brainstorming 作为有界设计流程处理，不再追问已经确认的色卡和参考。

比较两种结构：A 票券原物式纵向层次；B 原版小圆角卡加左右操作区。选 A，因为用户要求复刻 REF_28，B 的挂孔、分区和海报比例弱，与参考差距过大。

参考测量：REF_28 中票券约 x477–805、y229–1006，宽高约 1:2.37；不把设备边框或右侧活动时间表算进票根。新券基准 300×708，约 1:2.36。构造为挂孔/品牌、信息栏、主视觉、摘要格、条码与齿边；文字数据均为排版示例，不能当真实到访或门票。

无照片版主视觉用 START 原创几何图形和旅行短句；照片版让照片占主视觉，不缩成小贴图。照片使用用户参考 REF_12 中的山湖局部，通过 CSS 展示裁切，原文件字节不改；仅用于排版示例，不是用户拍摄或艺人到访证据。若用户认可版式，正式原型读取用户实际上传照片。

Logo 使用原透明 PNG；咖啡色来自原文件，不重绘。功能字体系统无衬线，票面小型元数据用等宽字体。基色燕麦/亚麻/深咖啡，原创图形使用冰蓝/湖蓝/芒果/叶绿，不铺九色。照片版和无照片版共享券形及信息网格。

REF_28 是布局参考，原 Figma 商标、活动信息、扫描提示不复制；装饰条码明确不可扫码。挂孔/挂绳只是视觉构造，不模拟可拖动交互。没有假手机或浏览器边框。

Open Design 本批使用独立 ticket-visual-v1/ 展示静态可编辑源，生成引擎是否成功与预览是否可用分别记录。此前已审阅 Motion（https://github.com/motiondivision/motion/blob/main/README.md）：成熟动画及测试方式可复用，不能提供票根排版或角色素材，本批无需动画依赖；票券布局以用户参考为直接依据，无上游代码复制。
