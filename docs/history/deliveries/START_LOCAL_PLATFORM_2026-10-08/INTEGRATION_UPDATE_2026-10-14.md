## 本轮完成
恢复本地 PostgreSQL/平台 4330、高德代理 4325、已有 Qwen2.5-1.5B 模型 4328。未购买服务、未下载模型、未连接云端、未输出密钥。

投稿页地图按钮接入既有高德选点页面。使用来源、iframe 窗口、随机 token 三重核验；地点名称、城市及坐标回填。手动改动名称或城市时清除旧坐标，避免错误关联。地图弹窗关闭及页面切换清理监听器。

文字识别接入本地候选提取接口，支持加载、空结果、失败重试及离页取消，原文保留；只展示原文存在的名称，先核对地图再提交，不自动发布。普通已验证用户可调用提取接口，未登录仍拒绝。正式身份尚未配置，因此当前公开页面不能完成登录后的提取及投稿写入；该流程用隔离 fixture 验证，不视为真实微信验收。

使用 Interaction Design 与 Apple Design 的反馈、错误恢复、清晰操作原则，保留既有版式。

## GitHub 参考与取舍
审阅 https://github.com/ggml-org/llama.cpp （ggml-org，MIT；页面显示约 131k 星标，提交页面缓存可见 2026-09 的持续维护记录，并非当天提交证明）。检查 tools/server/README.md 与 tools/server/tests/unit/test_chat_completion.py。
