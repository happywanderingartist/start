# 路线卡片排序与剩余工作

路线投稿已移除上移、下移按钮。通过卡片顶部冰蓝拖动手柄排序，保留移除操作；填写区域不会触发拖动。键盘空格/Enter拿起或放下、方向键排序、Esc撤销。减少动态效果时取消位移动画；页面卸载销毁拖动实例。

## 开源依据

审阅 https://github.com/SortableJS/Sortable ，2026-10-15 GitHub API记录31198 stars，最近提交2026-03-24，SortableJS组织维护，MIT许可证，仓库包含tests与TestCafe配置。优点：无框架依赖、触摸拖动、自动滚动与手柄配置适合当前原生JS页面。局限：没有满足本产品的键盘排序和数据同步，需要自行补齐；上游测试不能替代当前表单验收。固定使用1.15.6官方ES模块，保留许可证，本地提供资源，不依赖运行时CDN。界面沿用Apple Design/Interaction Design原则和既有组合色卡。
