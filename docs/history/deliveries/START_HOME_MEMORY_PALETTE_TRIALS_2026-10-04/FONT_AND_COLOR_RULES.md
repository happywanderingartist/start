# 字体与配色规则

以下是后续原型的字体规范；本次是 Image Gen 静态视觉稿，并非已嵌入这些字体的可编辑页面。图片色彩受生成与摄影纹理影响，色号以 tokens.json 为准。

| 用途 | 字体 | 逻辑字号 / 字重 |
|---|---|---|
| Logo、首页 START WITH | 定制 START 艺术字字形资产 | 按固定比例缩放，不替换普通字体 |
| 页面大标题 | 苹方 PingFang SC | 28 / Semibold |
| 纪念卡主标题 | 苹方 PingFang SC | 32 / Semibold |
| 小标题 | 苹方 PingFang SC | 18–20 / Medium或Semibold |
| 卡片标签 | 苹方 PingFang SC | 16 / Medium |
| 正文、按钮 | 苹方 PingFang SC | 14–16 / Regular或Medium |
| 步数、辅助文字 | 苹方 PingFang SC | 12 / Regular |
| 英文功能文字 | SF Pro | 与对应中文同级 |
| 票券日期与编号 | SF Mono | 10–12 / Regular |

正文行高1.4，标题1.15；艺术字仅用于 Logo 与首页品牌标题。后续非苹果设备需配置中文系统 sans-serif 回退；字体授权与跨平台部署不属于本次静态图交付。

A：冰蓝 #CBE5FE 配咖啡 #702720；燕麦 #FBF3E8 配橘色 #F24E07；橘色与咖啡色块配燕麦字。

B：草绿 #89BC62、粉紫 #DD88C1、天蓝 #407ADD 配奶油 #EBEFE0；奶油色块配草绿字。小字使用辅助深绿 #365B2D。

C：开心果 #B9C255、牛仔蓝 #5798D7 配冰霜 #E6F1FA；冰霜色块配牛仔蓝字。小字使用辅助深蓝 #245581。

娃娃仅在首页搜索框边缘，缩小至辅助元素；纪念卡不放娃娃，以文字、几何色块和照片为重点。纪念卡条码仅为装饰，不可用作真实凭证。
