# START · 艺人/城市/社群视觉批次
阶段：独立可编辑视觉稿；未接业务数据、登录、投稿、社群会员或真实物料。
最新结构：艺人页默认所有城市，路线横向卡片在上，无序地点集合在下；选城后同步筛选路线和地点，再按类型筛选地点；集合地图不连线。地点详情保留多个艺人贡献入口。
社群：每位艺人一个；城市在内部筛选；地点、路线、演出、公告、物料集市均保留。浏览不要求加入。
演出绑定场馆placeId，物料可引用eventId；具体交换集合点与场馆地址分开。发布者手动改状态，平台不记录交换完成，也不因演出变更提醒发布者。
未定：日常物料是否必须绑定演出、路线最少站数与单艺人限制、交换集合点公开粒度。本稿不通过演示自动定案。
参考地点来自用户五份图片，仅作排版参考，未核验当前营业、真实艺人到访、具体POI或授权。演出和物料为明确标注的界面示例。无虚构距离、路线耗时、热度或成员数。
视觉：继承已确认首页、原Logo；FBF3E8奶油底，702720咖啡主标题，3F241C正文，CBE5FE蓝色卡片与操作背景，3B7789按钮文字，F24E07少量强调，EAE5DA分组底。绿色与土黄不组合成主要界面。
本批使用Interaction Design、Apple Design、Hallmark；从GitHub审查iD和wanderer参考列表/地图组织及地点与路线分离。iD由OpenStreetMap维护，ISC，具贡献测试与实际编辑器部署；优点为分类/地图对象分离，局限为桌面OSM编辑器。wanderer由open-wanderer维护，AGPL-3.0，具路线上传/分享及部署说明；优点为路线目录与有序站点，局限为徒步场景/PocketBase/MapLibre，不提供START审批与艺人社群。未复制其代码，未运行上游测试；网页未提供可核对的最近提交日期，不能声称最近提交已核验。
