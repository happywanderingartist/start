# Hallmark · START 首页 study

Hallmark pre-emit self-critique（文档自评，非独立审查）：Philosophy 4 / Hierarchy 4 / Execution 4 / Specificity 5 / Restraint 4 / Variety 4。

本轮按 Hallmark study 的 Surface → Type → Structure → Motion → Rhythm 顺序，实际查看已确认 HOME_SOFT_ORANGE.png。它是浅暖纸面、咖啡主字、柔橘与冰蓝分块的发现页；主题不重新随机选择。标题用手绘块面建立邀请感，功能字采用清楚的无衬线角色；不能从截图认定具体字体名。

宏观结构为品牌邀请 → 搜索 → 四组轻层叠分类 → 薄步数条 → 三项底部导航。它不是网页 Hero/feature/footer 模板，Hallmark 的 landing-page archetype 不适用。纸片边缘形成档案感，组内只保留少量摄影和标题；首页搜索仍须比推荐、问号、娃娃和辅助数字更优先。

静态图中未观察到真实动画，motion 标为 unknown，而非臆测 GSAP、spring 或漂浮。对未来动作的建议是按压、局部翻页和有来源方向的展开；高频输入不播放入场动画。视觉节奏偏中等密度，上半部留白、下半部四组分类，重叠在组内发生，组间用空隙分开。

| Before（参考风险） | After（实施规则） | Why |
|---|---|---|
| 橘色小字或白色小字置于浅橘色块 | 实测 4.5:1 后选 ink 或调整该 token 的语义使用 | 参考图不替代可读性 |
| 纸片的层叠可能被理解为卡墙 | Search 用目录、Artist 用章节、Route 用轨迹、Place 用实用档案 | 各页共享风格而保留任务差异 |
| 手绘标题可能扩散成全站粗重文字 | 只品牌使用艺术字；功能文字保持轻盈和一致 | 避免报纸头条感与阅读疲劳 |
| 小娃娃参考姿态尚无独立批准资产证明 | 保留身份母版并登记姿态缺口 | 避免视觉方向与资产身份脱节 |

结论：可作为视觉规范的输入；不能作为五页已实现、动效已验收或 Figma 已完成的结论。本轮只 study 与建立执行合约，没有运行 Hallmark 默认页面生成或 redesign。
