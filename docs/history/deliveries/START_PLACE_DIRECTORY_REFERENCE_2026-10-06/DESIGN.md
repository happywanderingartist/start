# START 地点目录设计依据（结构建议，待视觉确认）

## 1. Visual Theme & Atmosphere
以已确认首页和Apple Music的内容层级为底座；地点目录清楚、直接，保留旅行杂志的摄影与编辑感。录屏参考用于信息结构，不替换首页原稿。

## 2. Color
组合色卡：#FBF3E8纸白主底，#EAE5DA辅助底，#3F241C主文字，#702720品牌强调；#CBE5FE冰蓝选中浅底，#3B7789蓝色行动，#F24E07橙色用于少量重点，#DD9F45和#839B64作为内容封面点色。禁止把绿色与土黄同时作为角色页主要配色。状态颜色须配文字，不只用颜色表达。

## 3. Typography
信息与按钮使用现有系统字体；地点名高于标签与区域。手写字体仅用于少量非关键杂志装饰。细节说明保证可读对比，不照搬录屏浅粉文字。

## 4. Spacing & Grid
目录使用单列列表；手机建议左右16px，点击区域至少44px；平板按现有系统网格扩展，保持列表信息可读。数值为本次建议，视觉稿需验证。顶部控件不占据大半屏。

## 5. Layout & Composition
保留首页音乐/文艺/电影/书店主题入口。目录内组织城市、搜索、艺人筛选、地点类型，以及列表/地图切换。地点类型建议餐厅、咖啡/甜品、景点、书店、商店、演出场所；同款机位作为编辑标签，与POI类型分开。

## 6. Components
列表行包含照片、地点名、类型/区域、可核验关联；标签过多时折叠为数量。详情含地址复制、去这里、来源说明；加入行程与打卡按阶段区分。投稿先选择真实POI，再补关联来源，不默认让用户手填未经确认坐标。

## 7. Motion & Interaction
列表和地图共享筛选结果与选中地点；返回恢复城市、筛选和滚动。地图拖动不悄悄改变目录范围，提供明确的“搜索此区域”。面板轻量移动，reduced-motion减少过渡。录屏未证明具体曲线和时长，本次不据此锁定动效参数。

## 8. Voice & Brand
直接使用“地点”“餐厅”“景点”“去这里”“加入行程”；不使用需要猜测的诗意功能名称。加载、空结果、失败、定位拒绝分别表达。

## 9. Anti-patterns
不复制RIIZE品牌、照片、粉色主题或原页面；不把全球展示数字当START真实数据；不把高德POI视为艺人到访证明；不显示假距离；不让首尔地图配深圳结果而无说明；不堆大卡和重复标签；未获视觉确认不接入现有原型。
