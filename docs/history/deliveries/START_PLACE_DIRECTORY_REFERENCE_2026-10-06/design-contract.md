# 地点目录参考合约

目标：为START地点目录下一批视觉稿提供依据，服务按城市、地点类型及艺人关联寻找地点的用户。当前交付为参考分析，不是页面实现或视觉获批。

| 证据 | 状态 | 观察/用途 |
|---|---|---|
| 用户47.23秒录屏，0–3秒 | observed | 城市/成员/搜索、列表地图切换、分类条、照片卡片 |
| 6–9秒、33–36秒 | observed | 地点详情：图片、成员、地址、导航、打卡、收藏及记录 |
| 15–18秒 | observed | 地图点位＋下方紧凑列表；首尔地图中出现深圳湾公园列表项 |
| 21–24秒 | observed | 城市列表和成员筛选面板 |
| 27–39秒 | observed | 类型选择状态；同款机位筛选后显示38个地点 |
| 42–45秒 | observed | 投稿城市/类型/地址/关联成员必填，说明与图片选填，页面声明审核后公开 |
| 用户历史确认 | provided | 保留首页原稿、组合色卡、原Logo、Apple Music底座，先视觉确认后实现 |
| 地图供应商、实时GPS、审核后台、导航结果 | unverified | 录屏不能证明，不作为实现事实 |

| Keep | Change | Do not copy |
|---|---|---|
| 城市、关联成员、地点类型三个维度 | 适配START城市/艺人/地点语义 | RIIZE品牌、角色照片及数字 |
| 列表/地图切换和紧凑地点行 | 两种视图使用同一结果集，保留返回状态 | 未解释的地图与列表错位 |
| 详情里明确的地址、导航、打卡 | START分离去这里/加入行程/打卡；来源独立展示 | 未核验到访、假距离、未经证实导航成功 |
| 投稿字段分组与审核告知 | POI选择后补充关联来源与证明 | 原粉色低对比主题及完整页面 |

采用一个方向：在START既定系统中建立清楚的地点目录，以轻量筛选、紧凑列表和地图面板提高找地点的效率，摄影与组合色卡保留杂志气质。首页保持原稿，只在对应入口进入目录。

风险与未知：录屏采样用于分析结构，不能测量完整动效；海外POI覆盖、坐标转换和导航可用性需独立验证；现有目录是否已有同类控件需实现前核对，避免重复。
