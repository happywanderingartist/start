# 下一步交接

先读本目录DESIGN.md、design-contract.md，以及上级REFERENCE_NOTE_002_PLACE_DIRECTORY_2026-10-06.md；工程阶段遵循 docs/superpowers/plans/2026-10-06-start-real-use.md。

下一件产物是地点目录视觉稿：正常列表、地图面板、筛选展开、空结果。先用Interaction Design确定结构，Apple Design优化系统层级，Hallmark检查文案与装饰，在Open Design制作/展示可编辑稿并导出直接图片。未获确认不得接入原型。

使用已批准的组合色卡和现有字体/Logo/素材，不下载或复用录屏中的人物照片；首页原稿保持不变。手机单列，平板利用横向空间，六种宽度与横屏需检查；图文不得溢出，重要信息不使用浅色文字。

首稿必须证明：城市/艺人/地点类型层级清楚，地点行名称容易扫读，标签不过量，地图与列表代表同一范围，详情去这里与加入行程层级明确。真实距离依赖授权定位，艺人关联需独立来源，海外地图和导航需另行验证。

通过视觉确认后才进入工程：先GitHub对照审查，再复用已有服务端AMap模块；测试筛选同步、返回恢复、来源表达与异常状态，区分设计、实现、配置和真实使用验收。
