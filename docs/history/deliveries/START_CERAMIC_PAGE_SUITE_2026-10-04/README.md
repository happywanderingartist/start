## 共同视觉基准

奶油底 #FEFAF0，咖啡主字 #542916，陶土主操作 #A13A1E，瓷蓝 #88B8CE，赭金 #B79858，蜜糖 #F1C166。品牌标题采用已确认的圆润手工块面感；中文功能文字使用干净的无衬线。模糊实景配颜色蒙版，卡组露出少量后层；一级导航固定 Start / Community / Me。沉浸 Journey 页面隐藏一级导航。

已逐张查看生成结果。像素色值、字号、边距并非确定性实现，正式可编辑界面需另行精确校正。角色使用现有参考，动作图仍须进一步做身份细节审核；角色母版没有修改。

## 数据与功能状态

首页步数3,200/6,000为示意值，细条圆点仅表示进度，不意味着步数可拖动修改。路线与地点为明确标注的示例，地址和艺人证据待补充；地图为示意图，未接入定位、导航或真实到访。Me 内容是演示档案。所有按钮均为视觉设计，未实现搜索、刷新、导航、收藏、计步、社区或旅程功能。

本批完成上述六个页面的视觉首稿；Artist Hub、Place Detail、Event Hub、到站、完成海报、START Book 内页等尚未在此批制作，完整产品范围仍以现有产品规格为准。
