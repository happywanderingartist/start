# 页面规格与验收边界

## 主流程

Home → Search → Route Detail → Journey Preview。一级 Community 与 Me 独立入口。四类搜索实体 Artist、Route、Place、Event 的长期架构保留，本批截图示例只展示已有路线/地点演示数据，不虚构艺人和活动。

## 首页步数

小号“今日步数”和小号计数同排；播放器式细线、圆形终点与色卡配色。这是只读进度：未来接入计步后以实际今日步数/用户目标计算，不能通过拖动改变实际步数。无计步授权时应显示“未连接步数”，不能用示意数冒充实时数据。

## 页面状态约定（尚未实现）

- 搜索：输入、加载、结果、空结果、错误重试；返回保留原查询与滚动；无结果不回退固定路线。
- 路线：说明艺人关联、证据与核验状态；示例只能预览，不伪装真实地点或核验结果；真实发布页可按产品规则提供开始路线。
- Community：区分已加入和推荐；无加入数据使用空状态；现场换物只属于指定 Event，不能加全站市场。
- Me：START Card说明身份，START Book为主要记忆入口；没有匹配分数、金币或养成状态。收藏和长期保存需登录后返回原任务。
- Journey：真实接入后地图与下一站为核心；到站由用户确认，定位拒绝时允许手动继续；跳过与结束不等于失败。截图示意地图不具有真实导航能力。

## 视觉检视

六张输出均已查看：首页细条/圆点、缩小步数字，搜索标签、路线来源标注、Community推荐与空状态、Me旅程册、Journey示意标签和预览限制可见。截图与逻辑390×844约等比，中文文字可辨认，无裁切主体；未进行代码、浏览器交互、屏幕阅读器或设备验收。不能称为上线成品。
