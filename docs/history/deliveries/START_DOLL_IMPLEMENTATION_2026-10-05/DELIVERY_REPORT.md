# 棉花娃娃 V6 实现交付

用户已确认 V6 无边框单人物与动态海边背景。本批已在原旅行、票根、Community、物料集市原型上接入 /me/doll，并在 Me 保留独立入口。未实施尚未批准的完整 Me、Card 或隐私页。

## 实现与素材边界

动态云朵与星光可暂停，页面隐藏时自动暂停；reduced-motion 关闭动画。固定槽位的弧形选择器支持触摸滑动、鼠标拖动、点击和键盘。保存、取消及同一浏览器会话内刷新恢复有效，损坏及不可写存储显示明确反馈。服装与表情暂不能叠加，更换时明确恢复另一项。配饰仅保存偏好，舞台始终保留人物，不制造佩戴效果。男娃只开放已有原始穿搭。人物本身未新增连续动作。

使用 Apple Design、Hallmark、Interaction Design 与 Animate/Emil 的既定规则；保持原 Logo、已确认首页与组合色卡。已审核 Embla Carousel 的固定槽位、transform 缩放设计：https://github.com/davidjerleke/embla-carousel 。优势是避免变化尺寸导致滚动位置重置；局限是不能解决资产分层和角色合成，本批使用原生滚动吸附，未复制仓库代码或新增依赖。历史核对约 8.4k 星、MIT、维护者 David Jerleke、测试及 playground；近期提交时间未可靠取到，未据星标推断质量。

## 实测

5 项娃娃状态单测、5 组主浏览器检查及4项额外检查通过，覆盖六种宽度、鼠标点击/拖动、键盘、保存取消刷新、角色限制、损坏存储、存储失败、背景运动/暂停、reduced-motion、hash入口与卸载样式。既有24项状态检查及40项旅程/记忆/票根/Community/物料集市浏览器检查通过。独立审查发现鼠标指针捕获阻断点击，修复后补入真实点击测试并通过。保护文件哈希见 evidence/BASELINE_HASHES.json。

Open Design 已同步 doll-implemented 并在真实预览中验证切换及保存成功。仅本地可编辑原型交付，未调用生产 API、未发布或提交 Git。
