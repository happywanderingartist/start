- START 到底是什么产品

- 页面和导航如何组织
- 领域对象如何拆分
- 多实体搜索如何设计
- 路线证据与“已核验/未核验”如何表达
- Journey、海报、START Book 如何衔接
- Community / Event / 现场换物如何收敛
- Me / START Card / Doll 如何定义
- Figma 正式设计要画什么
- Slice 应如何重拆，现有 Slice 001 哪些保留、哪些要改

## 产品一句话

START 是一款“先是追星产品、再是地图产品”的追星旅行与记忆产品：

> 可靠的追星地点数据 + 可直接复刻的路线 + 现场体验 + 追星记忆沉淀。

地图是基础设施，不是产品中心。
