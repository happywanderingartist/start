# START — Detailed PRD V2

日期：2026-10-01  
状态：产品主逻辑已锁定，进入规格化阶段。  
优先级：高于早期 Fan-route / v0.1 / v0.2 / 旧 PRD 中与本文件冲突的产品定义。

## 1. 产品定义

START 首先是一款追星产品，其次才是一款地图产品。核心问题不是“怎么从 A 去 B”，而是：

- 我喜欢的艺人去过哪里？
- 哪些地方真的和 TA 有关系？
- 我能不能直接复刻这条足迹？
- 到现场以后我要看什么、拍什么、怎么走？
- 最后能不能留下属于自己的追星记忆？

核心价值：

**可靠的追星地点数据 + 可直接复刻的路线 + 现场体验 + 追星记忆沉淀。**

## 2. 核心循环

用户体验循环：

`发现 → 决定去哪里 → 查看路线 → 开始复刻 → 到站 → 偶像故事/拍照 → 结束路线 → 自动生成纪念内容 → START Book`

内容循环：

`发现足迹 → 创建路线 → 添加地点与证据 → 自动初筛 → 人工审核 → 发布 → 他人复刻 → 补充/纠错`

UGC Route 属于 P0。

## 3. 一级导航

固定：

- Start：我要去哪里、看谁、做什么
- Community：我的圈子里正在发生什么
- Me：我是谁，我留下了什么

不增加 Go / Map / Journey / Collection / Doll 一级 Tab。

## 4. Start Home

核心句：

**Start with [ ... ] ?**

输入支持艺人、城市、地点、路线风格、Event、自然语言。

首页不是纯搜索页，还包括：

### 个性化悬浮推荐气泡
少量、缓慢漂浮，不形成传统 Feed。推荐优先依据：
1. 关注艺人
2. 已加入社群
3. 相似兴趣用户行为

### Doll 轻互动
可以走动、坐下、看气泡、偶尔短句、轻量动作。必须低频、不阻断、不抢主任务。不是电子宠物，不做饥饿、能量、喂养、等级、每日任务等。

## 5. Search

长期支持：

- Artist
- Route
- Place
- Event

技术架构不能长期只返回 Route。

## 6. Artist Hub

搜索艺人优先进入 Artist Hub。它不是百科页，而是行动入口：

> 从“我喜欢这个艺人”进入“我能去哪里”。

核心信息：
- 艺人照片
- 有足迹的城市
- 推荐路线

城市采用杂志目录式城市块。

## 7. 搜索城市

例如“台北”，默认展示优先级：

**Artist → Route → Place → Event**

先让用户看到“哪些艺人和这个城市有关”，再进入路线。

## 8. Route Result

优先信息：
1. 封面图
2. 为什么和偶像有关
3. 城市

距离、时长、站数为辅助。

## 9. Route Detail

信息优先级：
1. **可信**：为什么真的和偶像有关
2. **想去**：看完产生“我也想去”
3. **可执行**：我知道怎么走

第一屏：
- Hero
- 路线名称
- 城市 / 艺人
- 为什么值得复刻
- 简短路线故事

地图/交通后置。

可信度同时支持：
- 来源链接
- 来源类型
- 核验状态：已核验 / 部分核验 / 未核验 / 有争议

地点真实存在 ≠ 艺人真的来过，必须分开。

CTA：
- 主：开始路线
- 次：分享给朋友

## 10. Journey

点击开始路线后进入：

**Doll + 当前进度 + 下一站 + Map**

默认按推荐顺序，可跳站。

## 11. 到站

`GPS 接近 → 提示“你到了” → 用户确认`

定位关闭时允许手动确认。拍照不是强制打卡条件。

## 12. Arrival

到站后最重要：
1. 偶像在这里发生过什么
2. 推荐拍照机位 / 动作

拍照建议可以来自编辑/官方与用户贡献，必须标来源。

## 13. Journey 结束

用户可随时结束，不要求全部完成。显示真实完成状态，例如 `3/5`，但不定义为失败。

## 14. Completion Poster

结束后直接自动生成纪念海报。视觉主体：
- 实际去过的地点
- 用户拍摄照片
- 偶像相关元素

生成后允许轻量自由编辑：
- 文字
- 照片
- 贴纸
- 布局

不发展为完整 Canva/Photoshop。

## 15. START Book

不是历史记录列表，而是：

**相册 + 日记 + 收藏册**

视觉上像个人追星记忆册。自动保存海报、打卡记录、照片、路线、日期。

## 16. Create Route

入口统一“新建路线”，不强制第一步先选艺人/城市/标题。

地点核心信息：
- 地点名称
- 为什么和偶像有关
- 来源证据

地址/地图位置尽量通过搜索或地图选择补齐。

## 17. Moderation

`用户创建 → 自动初筛 → 人工审核 → 发布`

证据不足不一定禁止发布，但必须明确“未核验”。

## 18. Community

Community 不是微博式时间流。首页采用有主次的个性化混合推荐。

## 19. Event Hub

第一屏优先：
- Event
- 艺人
- 时间
- 地点
- 场馆
- 状态

之后再进入现场换物、相关路线、社群、现场内容。

## 20. 现场换物

P0 是 Event Live Trade Board，不是闲鱼。发布：
- 我有什么
- 我想换什么
- 我在哪个区域
- 怎么认出我

不公开精确 GPS，第一版不做完整 IM。

## 21. Me

Me 由 START Card、START Book、Doll 三者组合，有明确层级。

## 22. START Card

核心：
- 昵称
- 喜欢的艺人 / 本命
- 兴趣标签
- 和另一个用户的共同点

不做“92% 匹配度”。

## 23. Doll

P0 核心：
- Journey 陪伴
- 简单动作
- 简单表情

复杂换装、衣柜、经济系统后置。角色脸、五官关系、头身比例必须锁定。

## 24. P0 范围

Start：
- Start with [...]

- Artist Hub
- Route discovery
- Route Detail
- Place Detail baseline

Journey：
- 开始路线
- Map
- 进度
- 到站
- 跳站
- 自由结束

Memory：
- 自动纪念海报
- 轻量编辑
- START Book

UGC：
- 新建路线
- 添加地点
- 证据
- 自动初筛
- 人工审核
- 发布 / 未核验状态

Community：
- For You
- 我的社群
- Event Hub
- 现场换物

Me：
- START Card
- START Book
- Doll 基础版

## 25. 明确不属于 P0

- 完整 IM
- 拼房
- 完整搭子体系
- 精确附近的人
- 复杂信用系统
- 宠物养成
- Doll 经济系统
- 完整衣柜
- AI 全自动生成路线
- LLM/Vector Search
- 重型推荐系统
- 微服务
- 泛社交 Feed
- 二手市场
- 自研导航引擎

## 26. 产品判断标准

任何新功能先问：
1. 是否强化“复刻偶像足迹”？
2. 是否增加真实追星体验？
3. 是否把 START 拉向高德/小红书/微博/闲鱼/电子宠物/普通旅游攻略？
