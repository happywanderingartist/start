# 追星路线产品｜Codex 原型交接包

本文件夹用于把已确认的产品设计交接给 Codex，制作移动网页可点击原型。

## 本轮目标

只打通一条纵向主链：

`首页 → 安溥南京路线详情 → 路线进行中`

本轮验证用户能否：

1. 立即理解产品能帮助自己寻找或生成追星路线；
2. 看懂路线站点、顺序、距离和时长；
3. 开始路线、选择地图并继续下一站；
4. 从模拟外部地图返回后继续当前进度。

## 重要边界

- 这是低保真交互原型，不是正式生产版本。
- 不接真实 AI、后端、登录和地图 API。
- 不增加社区、交易、实时位置或聊天功能。
- 所有未核验的 POI、距离和时长必须明确标注为原型数据。
- 先保证任务清晰，再逐步调整玻璃质感、主题色和动效。
